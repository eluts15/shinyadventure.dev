Personal Projects

GPS Navigation & Autopilot

Rust · Raspberry Pi · github.com/eluts15/geo-rs
  • Building a Rust-based marine autopilot for a kayak on a Raspberry Pi, parsing NMEA sentences from a u-blox GPS module to track position and heading in real time.
  • Combines GPS heading with a calibrated magnetometer compass so heading stays available whether the vessel is moving or stationary, with hard-iron calibration to correct for magnetic interference.
  • Includes a standalone calibration tool that walks through a 360° rotation to derive the magnetometer's offset values, which then feed the hard-iron correction used at runtime.
  • In progress: closing the loop with PWM servo control for automatic course correction, using GPIO toggles for manual heading adjustment in the meantime.
